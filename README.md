# NumPy Real-World Practice Tasks

This project demonstrates the use of **NumPy** for real-world data analysis problems.  
It covers sales data, employee salaries, exam scores, random transactions, and correlation between study hours and exam scores.  

---

## 📌 Features
- Sales Data Analysis (Quarterly and half-yearly sales)
- Employee Salary Increment and Average Calculation
- Exam Scores Statistical Analysis (Mean, Median, Standard Deviation)
- Random Transaction Analysis (Min, Max, Average Bills)
- Study Hours vs Exam Scores Correlation (using NumPy correlation matrix)

---

## 🛠️ Installation
Make sure you have Python 3.x installed.  
Install NumPy using pip:

pip install numpy


# ▶️ Usage
Run the script:
python numpytask.py
